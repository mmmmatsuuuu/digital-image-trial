# digital-image-trial

【体験入学お土産サイト】画像のデジタル化（バイナリデータ）の仕組みを一瞬で体験・学習できるWebアプリです。中学校の技術科から高校の「情報Ⅰ」への学びにつながるロジックを解説しています。

## 🌐 公開URL

https://mmmmatsuuuu.github.io/digital-image-trial/

## 📋 プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| システム名 | 体験入学お土産用・デジタルデータ変換体験Webアプリ |
| ターゲット | 体験入学に参加した中学生、およびその保護者 |
| 目的 | 画像をアップロードし、ボタン一つでバイナリ（デジタルデータ）の特性を活かした画像変換を体験する。裏側にある「情報の技術（ロジック）」を直感的に学び、高校の「情報Ⅰ」への興味に繋げる |
| 動作環境 | スマートフォン（iOS / Android）、PCの各種ブラウザ（Safari, Chrome, Edge等） |
| 配布方法 | GitHub Pagesによる静的ホスティング（QRコード経由でアクセス） |

## 🛠 技術選定・開発方針

- **アーキテクチャ**: サーバーレス、フロントエンド（ブラウザ）のみで完結するSPA
- **主要技術**: HTML5, CSS3 (Tailwind CSS CDN), JavaScript (Vanilla JS / ES Modules / Canvas API)
- **コード品質方針**: ES Modules（`type="module"`）を採用し、役割（データ、ロジック、UI制御）ごとにファイルを完全に分離・カプセル化する

## 📁 ディレクトリ構成

GitHub Pagesの仕様（リポジトリ名がURLのサブディレクトリになる）でパスエラー（404）が起きないよう、すべてのインポート・読み込みは**相対パス（`./js/...`）**で記述する。

```
repository-root/
├── index.html       # メイン画面（骨組み。Tailwind CSS読み込み、js/main.js をモジュールとして呼び出し）
└── js/
    ├── main.js      # 【司令塔】DOM操作、ファイル入出力、イベントリスナー、全体の制御
    ├── effects.js   # 【画像ロジック】Canvasの ImageData を受け取り、加工して返す純粋関数群
    └── content.js   # 【テキストデータ】中学生向けのエフェクト解説文（タイトルと説明）のオブジェクト
```

## 🎨 画面構成とUI/UX

中学生がワクワクするような、サイバーかつポップなダークモード風デザイン（背景はダークグレー系、アクセントカラーはネオンブルーや紫）。

1. **ヘッダー**: キャッチコピー「デジタルデータの魔法を体験しよう！」
2. **アップロードエリア**: ファイル選択ボタン（スマホの場合はカメラ起動対応）
3. **ワークスペース（Canvas）**: 画像が画面幅に合わせてアスペクト比を維持したままリサイズ表示される領域
4. **コントロールエリア**: ［🌙 ダークモード］［🪞 左右はんてん］［⏳ レトロ白黒］［⚡️ サイバーバグ］
5. **解説エリア**: ボタンを押すと現れる中学生向けの解説文
6. **アクションエリア**: ［💾 加工した画像を保存する］ボタン

## ⚙️ 各ファイルの機能要件

### `js/content.js`（データの分離）

各エフェクトの解説文（タイトルと説明）をオブジェクト化してエクスポートする。

### `js/effects.js`（画像処理ロジック）

DOMや画面要素には一切触れず、`ImageData` を加工して返す純粋関数（Pure Function）を実装する。

- `applyInvert(imageData)`: `255 - 現在のピクセル値` をRGBそれぞれに適用（ネガポジ反転）
- `applyMirror(imageData)`: 横1列ごとのピクセル配列（4バイト単位）を左右反転させる
- `applyGrayscale(imageData)`: 各ピクセルの R, G, B の平均値を新たなRGB値として上書きする
- `applyGlitch(imageData)`: ランダムな高さから数十行分のピクセルデータをランダムなピクセル数だけ横にシフトさせる。空いた隙間は黒で埋める

### `js/main.js`（全体の司令塔）

- 画像読み込み時、デバイスの画面幅に合わせてアスペクト比を保ったまま縮小してCanvasに描画
- 各ボタンのクリックで `effects.js` の関数を実行し、`ImageData` をCanvasに再描画
- 同時に `content.js` から解説テキストを取得し、解説エリアを書き換える
- 保存ボタンで `canvas.toDataURL("image/png")` を用いて画像をダウンロード
